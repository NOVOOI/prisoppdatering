Last opp under WooCommerce → Produkter → Importer. Huk av «Oppdater eksisterende produkter».
Import-steg
Steg 01
Last ned CSV-filen
Klikk «Last ned» nedenfor. Filen inneholder kun SKU og pris.
Steg 02
Åpne WooCommerce-import
Produkter → Alle produkter → Importer øverst på siden.
Steg 03
Konfigurer import
Huk av «Oppdater eksisterende produkter». SKU → SKU, pris → Vanlig pris.
Steg 04
Verifiser etter import
Spot-sjekk 3–5 produkter manuelt for å bekrefte at prisene er riktige.
